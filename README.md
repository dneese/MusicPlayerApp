# Music Player Pro

Современный музыкальный плеер для Android (Flutter), вдохновлённый Spotify / YouTube Music / AIMP / PowerAMP.

## Особенности

- **Воспроизведение локальной музыки** с устройства (MediaStore + резервное сканирование файловой системы).
- **Фоновая игра** — продолжает играть при сворачивании приложения (audio_service + just_audio). Если фоновая служба недоступна, автоматически используется встроенный (in-process) обработчик, так что плеер всегда готов играть.
- **Прослушивание сейчас**: большой экран «Сейчас играет» с обложкой, перемоткой, транспортом, повтор (off/all/one) и перемешиванием.
- **Очередь / шторка**: нижнее меню со списком треков для быстрого переключения.
- **Плейлисты** (создание, переименование, удаление, добавление треков; сохраняются локально).
- **Избранное** — отметка треков сердечком (сохраняется).
- **Сортировка** по названию, исполнителю, альбому, жанру, длительности, дате добавления и папке/файлу.
- **Меню трека** (⋮ или долгое нажатие): воспроизвести, перейти к альбому, добавить в плейлист, добавить в избранное, поделиться, редактировать теги, информация о файле.
- **Редактирование тегов** (название, исполнитель, альбом) — применяется к отображению (запись во встроенные теги файла ограничена хранилищем Android).
- **Настройки**: тема оформления (светлая/тёмная/как в системе), сортировка по умолчанию.
- **Выдвижное меню** (гамбургер): разделы «Песни», «Плейлисты», «Избранное» и «Сортировка».
- Динамическая акцентная подсветка по цвету обложки (palette_generator).
- Material 3, приятный современный интерфейс.

## Сборка

```bash
flutter pub get
flutter build apk --release --split-per-abi
```

Для вашего устройства (Android 12, arm64) используйте `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`.

CI собирает релиз из git-тега `vX.Y.Z` и публикует APK/AAB в GitHub Releases.
